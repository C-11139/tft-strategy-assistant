# 🎮 TFT-AI-Copilot (金铲铲/云顶之弈 实时战术副驾驶)

## 📖 项目简介
一款基于多模态大模型与RAG（检索增强生成）的桌面级AI助手。通过全局热键（F8）无感触发，结合PyQt6透明悬浮窗，为玩家提供实时的战术分析与语音主动预警。彻底摆脱“被动问答”，实现“主动副驾驶”的Agent体验。

## 🚀 核心亮点
1. **多模态视觉链路**：基于 MSS 截取屏幕 -> Pillow 压缩图像 -> GLM-4V 多模态识别，输出结构化 JSON 状态。
2. **Agent 主动响应**：引入规则引擎（血量/金币阈值）与 Edge-TTS 语音合成，实现从“被动问答”到“主动语音预警”的产品升级。
3. **桌面级悬浮交互**：基于 PyQt6 实现透明无边框悬浮窗，通过全局快捷键（F8）触发，完美解决“切出游戏界面打断操作”的痛点。
4. **工程化排坑**：解决“UI遮挡截图的观察者悖论”及“系统播放器弹窗遮挡游戏画面”等实际工程问题。

## 🛠️ 技术架构
- **语言**：Python
- **大模型**：智谱 GLM-4V（视觉识别）、GLM-4（战术决策）
- **桌面UI**：PyQt6、MSS、Pillow、Keyboard（全局热键）
- **语音合成**：Edge-TTS、Pygame（静默后台播放）

## ⚙️ 本地运行教程
### 环境依赖
`pip install -r requirements.txt`

### 启动助手
`python pet.py`

### 如何使用
1. 运行程序，屏幕出现透明悬浮窗。
2. 打开《金铲铲之战》模拟器。
3. 按下键盘 **`F8`** 键。
4. 助手会自动截图识别，弹窗提示战术，并在血量危险时进行语音播报。
